## The entry

A program that writes one horror story in exactly two sentences to
`entry.txt`. The story is a quiet domestic scene — a child's drawing of
her family on the fridge — reframed by the second sentence into something
far worse, with the horror implied rather than explained.

> My daughter drew our family on the fridge: me, her mother, and the tall man who stands behind us at dinner. Her mother died before she was born.

## Run locally

Requires Node 22 or later. No dependencies to install — the program uses
only the Node standard library.

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

The output is deterministic: every run writes the exact same bytes.
